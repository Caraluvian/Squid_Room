# Squid_Room

An early Three.js room study using Splatoon 3 model previews from The Models Resource.

## Run

```bash
npm install
npm run dev
```

## Included model sources

- Arcade Game — asset 363058
- Blue / Red Bucket — asset 363059
- Monkey-Crab Cushion — asset 363061

These Nintendo assets are included for a non-commercial fan prototype. They should not be treated as original or commercially licensed project assets.
